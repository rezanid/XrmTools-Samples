# XrmTools Samples

Sample projects, tutorials, and practical examples for [XrmTools](https://github.com/rezanid/xrmtools), a Visual Studio extension that simplifies Microsoft Dataverse and Power Platform development.

This repository accompanies the XrmTools video tutorials and provides source code you can explore, build, and experiment with.

## What's Inside?

The repository will grow as new tutorials and examples are published.

- **Tutorials** — Step-by-step examples accompanying XrmTools videos, covering plugin development, registration, deployment, troubleshooting, and more.
- **Samples** — Standalone examples demonstrating specific XrmTools features and development scenarios.
- **Showcase** — An evolving application that brings together multiple XrmTools capabilities in a realistic Power Platform solution.

Each tutorial has its own folder and README, so you can follow a particular video without needing to check out an older Git revision.

## Getting Started

1. Install [Visual Studio 2022](https://visualstudio.microsoft.com/) with the necessary .NET development workloads.
2. Install [XrmTools](https://marketplace.visualstudio.com/items?itemName=rezanid.XrmTools) from the Visual Studio Marketplace.
3. Clone this repository or download it as a ZIP.
4. Open the solution associated with the tutorial you want to follow.
5. Follow the instructions in that tutorial's README.

Some examples require access to a Microsoft Dataverse environment.
